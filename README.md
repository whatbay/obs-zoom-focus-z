# OBS Zoom Focus Filter - Practical Edition

OBS Studio用「画面の好きな場所を拡大する」フィルターです。

## 想定操作

- 左クリック：クリックした場所を拡大中心にする
- 左ボタンを押したままドラッグ：拡大位置を移動
- マウスホイール：拡大・縮小
- ダブルクリック：倍率と位置をリセット
- ESC：位置を中央に戻して倍率を1倍に戻す
- プロパティから倍率、中心位置、操作の有効/無効を設定

## 使い方

1. OBSでビデオキャプチャー等の映像ソースを作る
2. そのソースの「フィルタ」を開く
3. 「Zoom Focus Filter」を追加
4. 「対話」を開いて映像をクリック/ドラッグ
5. ホイールで倍率を調整

OBSの仕様上、マウスによる操作イベントは OBS_SOURCE_INTERACTION を持つソースに対して発生します。
そのため「OBSメインプレビュー上で、フィルターが付いたソースを直接クリックして操作する」というより、
対象ソースの「対話」画面を使う方式です。

## Windows

GitHub ActionsでWindows x64ビルドを行えるプロジェクトです。
この実行環境ではVisual StudioによるWindows DLLのコンパイルを実行できないため、DLLそのものは同梱していません。
